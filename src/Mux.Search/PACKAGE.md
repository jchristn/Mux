# Mux.Search

Web-search abstractions and provider clients used by [**mux**](https://github.com/jchristn/Mux) and its engine package, [`Mux.Core`](https://www.nuget.org/packages/Mux.Core).

`Mux.Search` provides a small, dependency-free surface for discovering web results through pluggable providers (Tavily and You.com), returning structured candidate results with URLs and snippets. It is consumed by `Mux.Core`'s `web_search` tool and can be used on its own.
